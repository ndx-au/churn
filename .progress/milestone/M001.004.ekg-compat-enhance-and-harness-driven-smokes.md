## Decisions (from research + execution)

- Support both document frontmatter (`--- type: ...`) + folder frontmatter.yaml (no ---) for drop-in doctree use in ekg.
- Use `semantic_tags` for folders per ekg convention; `tags` for document concepts.
- Emit clear hierarchical headings in bodies (aids ekg section extraction via goldmark).
- Keep permissive: churn never fails on unknown OKF fields; ekg parser is tolerant.
- Continue using absolute `/` or stable relative links where possible.
- For binaries later: encourage writing to `_static/` subdir.
