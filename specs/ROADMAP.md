# CHURN Project Roadmap

**Overall Goal:** Production-ready, extensible OKF converter branded as the community reference implementation.

**Milestones (M{nnn} format)**

- M001 — Foundations & Plugin Architecture
- M002 — Core Drivers & Connectivity
- M003 — Decoding, Extraction & Normalization
- M004 — OKF Rendering, Validation & Compliance
- M005 — CLI Polish, Packaging, Docs & Community Launch

Each milestone ends with a usable slice and passing tests.
